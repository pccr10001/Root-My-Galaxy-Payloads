This record contains the exact offline inputs and derived values for profile
`e1q-S9210ZHS5CZB2`. It is a Snapdragon Galaxy S24 China firmware port. The
payload and KernelSU artifacts are build- and static-audit-verified only; they
have not been loaded on an SM-S9210.

The payload explicitly sets `MM_STRUCT_SZ=0x400` and `MM_ORDER=3`. The
upstream `0x500` default placed the mm-struct reclamation code on invalid slab
object boundaries and could reboot the phone immediately after the late drain.

The app payload also rejects slide candidates outside object indices `27..30`
and caps the late CPU-partial drain at two triggers. The immediate reboot trace
showed a low-slot candidate (`object_index=2`) reaching the legacy 32-trigger
drain; these guards make that unsupported geometry fail safely instead.

The trace event registration index gives `sched_blocked_reason` event ID `106`.
The `worker_thread -> schedule` return address is `0x000da848`, and the
`pselect6` waiter starts at word shift zero.
